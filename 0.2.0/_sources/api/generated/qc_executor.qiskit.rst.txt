Dependencies
------------

Install with ``pip install qc-executor[qiskit-full]``. Requires:

* ``qiskit>=1.2.0``

* ``packaging>=21.0``

* ``qiskit-aer>=0.12.0``

* ``qiskit-ibm-runtime>=0.18.0``
