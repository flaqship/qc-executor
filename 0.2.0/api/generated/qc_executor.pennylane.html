    Executor¶

    class qc_executor.pennylane.PennyLaneExecutor(backend='default.qubit', *args, shots=None, seed=None, log_file=None, log_level='WARNING', caching=None, cache_dir='cache', max_cache_size=4096, **kwargs)[source]¶

    Bases: ExecutorBase

    Quantum circuit executor backed by PennyLane.

    The backend parameter accepts either a string (device name) or a ready-made Device instance.

    Parameters:

    • backend (str or qml.devices.Device) – PennyLane device name or an already-instantiated device. Defaults to "default.qubit".

    • *args – Positional arguments forwarded to pennylane.device() (only when backend is a str). The most common positional argument is wires.

    • shots (int, optional) – Number of shots for sampling. Defaults to None.

    • seed (int, optional) – Random seed for reproducibility. Defaults to None.

    • log_file (str, optional) – Path to the log file. Defaults to None.

    • log_level (str) – Logging level ("DEBUG" / "INFO" / "WARNING" / "ERROR"). Defaults to "WARNING".

    • caching (bool, optional) – Whether to use caching. Defaults to None.

    • cache_dir (str) – Directory for caching. Defaults to "cache".

    • max_cache_size (int | None, optional) – Maximum number of entries kept in each in-memory cache; None makes them unbounded.

    • **kwargs – Keyword arguments forwarded to pennylane.device() (only when backend is a str). Typical keys are config and custom_decomps.

    Note

    If shots is set and a PennyLane config object containing a shots value is passed via **kwargs, the config value takes precedence and a UserWarning is emitted.

    Devices are created once during initialization and are never recreated dynamically. The configured device must therefore provide enough wires for every executed circuit.

    Return the number of shots.

    Circuit¶

    class qc_executor.pennylane.PennyLaneCircuit(num_qubits=0, num_clbits=0, *, measurement=None, _ir=None)[source]¶

    Bases: QuantumCircuitBase

    A quantum circuit that compiles to PennyLane.

    Built like any other circuit – PennyLaneCircuit(2) then circuit.h(0) – or converted from an existing one with from_quantum_circuit(). Compilation into PennyLane operations is lazy and re-runs whenever the instruction store changes.

    Parameters:

    • num_qubits (int) – Number of qubits in the circuit.

    • num_clbits (int) – Number of classical bits, for mid-circuit measurement.

    • measurement (Optional[str]) – What the built callable returns besides applying the gates. None (default) returns nothing, for a caller that attaches its own measurement – as the executor does when it pairs the circuit with an observable. "probs" returns qml.probs over every qubit and "state" returns qml.state(), which makes the callable a complete QNode body, e.g. for qml.metric_tensor. Circuits derived through copy, invert or assign_parameters start again from None.

    • _ir (CircuitIR | None) – Adopt this instruction store instead of starting empty.

    Raises:

    ValueError – If measurement is not None, "probs" or "state".

    Operator¶

    class qc_executor.pennylane.PennyLaneOperator(paulis=None, coeffs=None, num_qubits=None, *, _ir=None)[source]¶

    Bases: QuantumOperatorBase

    An observable that compiles to a PennyLane measurement.

    Built like any other operator – PennyLaneOperator(["ZI"], [1.0]) – or converted from an existing one with from_quantum_operator(). Compilation is lazy, so the inherited algebra (compose(), adjoint(), apply_layout(), …) works without paying for it.

    Parameters:

    • paulis (Optional[Sequence[str]]) – Pauli labels, qubit 0 leftmost.

    • coeffs (Optional[Sequence[Any]]) – One coefficient per label.

    • num_qubits (int | None) – Width, required only when no labels are given.

    • _ir (PauliIR | None) – Adopt this representation instead of building one.

    property parameter_dimensions: Dict[str, int]¶

    Number of parameter occurrences, keyed by vector name.

    property parameter_names: list¶

    List of operator parameter names

    property free_parameters: set¶

    Return the set of free (non-bound) parameters in the operator.

    property pennylane_words: List[Any]¶

    The compiled PennyLane Pauli words.
