    • qulacs>=0.6.4.1

    Circuit¶

    class qc_executor.qulacs.QulacsCircuit(num_qubits=0, num_clbits=0, *, _ir=None)[source]¶

    Bases: QuantumCircuitBase

    A quantum circuit that compiles to Qulacs.

    Built like any other circuit – QulacsCircuit(2) then circuit.h(0) – or converted from an existing one with from_quantum_circuit(). Compilation into Qulacs operations is lazy and re-runs whenever the instruction store changes.

    Parameters:

    • num_qubits (int) – Number of qubits in the circuit.

    • num_clbits (int) – Number of classical bits. Qulacs cannot execute mid-circuit measurement, so these exist only for interface parity.

    • _ir (CircuitIR | None) – Adopt this instruction store instead of starting empty.

    get_gradient_outer_jacobian(gradient_parameters=None)[source]¶

    Returns the outer jacobian needed for the chain rule in circuit derivatives.

    Qulacs does not support multiple parameters and parameter expressions, so we need to calculate a transformation which also includes the gradient of the parameter expression.

    Parameters:

    gradient_parameters (Parameter | List[Parameter] | None) – Parameters to calculate the gradient for

    Operator¶

    class qc_executor.qulacs.QulacsOperator(paulis=None, coeffs=None, num_qubits=None, *, _ir=None)[source]¶

    Bases: QuantumOperatorBase

    An observable that compiles to Qulacs operators.

    Built like any other operator – QulacsOperator(["ZI"], [1.0]) – or converted from an existing one with from_quantum_operator(). Compilation is lazy, so the inherited algebra (compose(), adjoint(), apply_layout(), …) works without paying for it.

    Parameters:

    • paulis (Optional[Sequence[str]]) – Pauli labels, qubit 0 leftmost.

    • coeffs (Optional[Sequence[Any]]) – One coefficient per label.

    • num_qubits (int | None) – Width, required only when no labels are given.

    • _ir (PauliIR | None) – Adopt this representation instead of building one.

    property parameter_dimensions: Dict[str, int]¶

    Number of parameter occurrences, keyed by vector name.

    property parameter_names: list¶

    List of operator parameter names

    property free_parameters: set¶

    Return the set of free (non-bound) parameters in the operator.

    property terms: List[str]¶
